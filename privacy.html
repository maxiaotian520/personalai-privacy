PersonalAI Privacy Policy

Last updated: 2026-11-02

PersonalAI is a desktop application used only by its owner, on the owner's own computer. It has no other users.

What data the app accesses

With the owner's permission, the app accesses the owner's Gmail account to read messages, change labels (for example read, starred, archived, deleted) and create or send replies that the owner approves.

How the data is used and stored

  • Gmail data is processed and stored only on the owner's computer.
  • Sign-in tokens are kept in the Windows credential store on that computer.
  • When the owner asks for help, selected message content may be passed to AI tools that the owner has set up on the same computer.

What the app does not do

  • It does not collect data on any server operated for this app.
  • It does not sell, share or transfer Google user data to anyone.
  • It does not use Google user data for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
